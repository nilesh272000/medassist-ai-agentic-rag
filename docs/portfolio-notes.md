# Interview Notes

**Why RAG?** The application can ground responses in a controlled knowledge collection instead of relying only on model memory.

**Why Agentic RAG?** The graph evaluates evidence, rewrites weak queries and refuses when evidence remains insufficient.

**Why LangGraph?** Conditional state transitions make retrieval, grading, retry and fallback explicit.

**Why ChromaDB?** Persistent local vector storage keeps the portfolio project easy to reproduce.
